# FCC Technical Documentation Page

Learning exercise for **HTML structure & CSS navigation**

## 🎯 Objective

**Main goal**: Build a technical documentation page meeting freeCodeCamp's Responsive Web Design certification requirements.

**Context**: This project is part of the freeCodeCamp Responsive Web Design certification. It focuses on creating a structured documentation layout with fixed navigation, internal linking, and readable content presentation. The documentation presents various fitness programs for a fictional gym. Prerequisite knowledge includes semantic HTML, CSS positioning, and responsive design techniques.

## 🛠 Tech Used

- HTML5 (semantic elements, navigation)
- CSS3 (Flexbox, fixed positioning, media queries)
- Responsive Design
